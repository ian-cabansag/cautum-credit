# Course evidence checklist · MGT 409 Fall 2026

Authoritative assignment: https://zlisto.github.io/mgt_409_fa26/project_requirements.html

- GitHub code + reproducible README + `.env.example`, no live keys.
- `report.html`, **10–15 printed pages**: title, motivation, competition, agents/tools, real run, actual tokenomics, demonstrated safety, measured impact, limitations.
- `slides.html`, ≤10 slides. One file readable by double-click; reveal.js CDN with self-contained fallback as needed.
- Local run under 10 minutes, `.env` from repository or one folder above; course `PORTKEY_API_KEY` with `gpt-6-luna` or own `OPENAI_API_KEY`.
- A real user/tester and observed baseline is the strongest evidence. No invented claims; if no real user yet, say so.

## Screenshots required for final report

5. Hostile CSV or PHI-header rejection.
6. API log / token usage from successful AI test (if any).

## Real tokenomics
Record model ID, model provider, prompt/input tokens, cached input tokens, output tokens, total successful runs, failure count. Retrieve published token unit prices for the *exact* provisioned model/provider and timestamp the source. Formula:
`cost_per_run = (uncached_input_tokens × price_in + cached_input_tokens × price_cached + output_tokens × price_out) / 1,000,000`.
Use real observed medians/p95 across at least 5 repeated runs, if permitted. Extrapolate per user/month and per 100/10,000 users with disclosed assumptions. Cost tables for unspecified model pricing are `TBD`, not `$0` or guesses. Offline mode uses zero model tokens and has a different quality/coverage tradeoff.

## Safety demonstration
Attempt unknown `patient_name` or MRN column upload; show visible rejection. Attempt hostile label with `=IMPORTXML(...)` and assert 400. Real LLM prompt injection should be tested only with a permitted key and with prompts safely embedded in synthetic data; show model response and audit. The static parser blocks many payloads by design but cannot guarantee complete prompt-injection prevention.
